统一方案、数据口径与防未来函数说明

集中提炼自 AI公园 GitHub 开源金融项目榜单、亿点毛噜噜 SMC 框架、simonlin1212/a-stock-data V3.10.4 与 etf.maomaoci-a.com

一、工程闭环与可维护架构

吸收 daily_stock_analysis / tick-stock-panel / etf.maomaoci-a.com 的轻量化思路：采用 「Python 定时取数引擎 → 静态 JSON/JS 快照 → 纯前端 ECharts 看板」 三层解耦结构，ECharts 引擎本地内置零外部 CDN 依赖，支持 GitHub Pages 公开分享与单文件离线转发。

二、免Key数据源优先级与口径防坑

遵循 a-stock-data V3.10.4 铁律：行情优先走不封 IP 的腾讯财经（三入口轮换）、中证官方（H00300/H11023/H11022）、上金所官方（Au99.99）、新浪期货（AU0）及上交所/深交所官方 ETF 份额，并配置增量缓存兜底。

三、SMC 聪明钱指标与防未来函数

参考 LuxAlgo SMC 与招商证券研报框架，在日K上区分波段结构（L=10，实线）与内部结构（L=3，虚线），以收盘价突破判定 BOS/CHoCH，以 High/Low 触碰判定订单块（OB）失效。重要提示：分形支点存在 L 个交易日确认滞后，订单块在结构突破日才生成并向左锚定参考K线，复盘时切勿将左端锚点误作当下实时信号；Weak Low 仅代表顺势角色，不等于底部确认。
