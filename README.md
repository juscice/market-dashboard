# A股与大类资产实时投研监控看板（三独立网址版）

本项目采用**纯静态前端实时直连行情 + 本地内置 ECharts（零外部 CDN 依赖）**设计，并将 A股宽基、黄金宏观与个股拆分为**三个独立网址看板**：

- **主市场看板（4大核心项目）**：`index.html`（公网网址 `/`）
  1. 沪深300全收益指数 vs 二级债基指数（波动收敛走势、历史跌破红圈与灰带、线性/对数切换）
  2. “国家队”持有全A宽基ETF份额与动向走势（16只重仓宽基ETF总份额、估算净申赎、中信期货净空头、官方持仓基准）
  3. 科创50（`000688.SH`）技术分析走势图（日K + 成交量 + MACD/RSI + SMC聪明钱结构）
  4. 创业板指（`399006.SZ`）技术分析走势图（日K + 成交量 + MACD/RSI + SMC聪明钱结构）
- **黄金与美元/美债宏观独立看板**：`gold.html`（公网网址 `/gold.html`）
  - 支持一键切换伦敦金现（`XAU/USD`）、黄金股ETF（`517520.SH`）与黄金ETF（`518880.SH`），在黄金日K图上实时叠加**美元指数（DXY）**与**美国10年期、2年期国债收益率**走势（支持反轴负相关对照），并附带专属宏观联动对比图、**10Y−2Y 期限利差（bp）**、60日相关性及 SMC 订单块/结构明细表。
- **燕东微专属独立看板**：`yandongwei.html`（公网网址 `/yandongwei.html`）
  - 燕东微（`688172.SH`）前复权日K + 科创板量价与市值校准快照 + SMC 聪明钱结构图与关键位明细表。

## 实时更新机制

- **打开即最新**：每次打开网页立即在浏览器端直连最新实时行情并重算全部技术指标、SMC 结构与简报，无需等待定时任务。
- **每分钟自动刷新**：页面处于可见状态时每 60 秒自动拉取最新行情并平滑刷新图表（保留当前周期与图层开关状态）。
- **实时动态简报**：每次点开简报（点击导航「实时简报」、展开简报或点击「重新生成」）均按当下最新行情即时生成波浪理论 × 通道理论 × 宏观投研简报。

## 本地运行与更新基线快照

```bash
pip install -r requirements.txt
python scripts/update_daily.py
python serve.py 8080
# 主看板:   http://127.0.0.1:8080/
# 黄金宏观: http://127.0.0.1:8080/gold.html
# 燕东微:   http://127.0.0.1:8080/yandongwei.html
```
